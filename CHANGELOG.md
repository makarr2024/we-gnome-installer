# Изменения

## v1.1.0 — 2026-10-27

- Значки рабочего стола больше не моргают при клике по рабочему столу (GNOME 47+ с DING): патч для расширения
  GNOME держит обои под значками в том же кадре. Патч накладывается снова при каждом входе, если WE Manager
  переустановит расширение.
- Обои в списке приложений больше не сплющены: в обзоре они обрезаются, как обычный фон GNOME.
- WE Manager стартует при входе с задержкой 10 секунд — раньше он иногда успевал раньше расширения, и обои не включались.
- Установщик больше не зависает в конце, если запускает WE Manager сам.
- Проверено на Ubuntu 26.04 (GNOME 50).

## v1.0.0 — 2026-10-26

Первый выпуск.

- Установка одной командой: `curl -fsSL https://raw.githubusercontent.com/makarr2024/we-gnome-installer/main/get.sh | bash`.

- Установка WE Manager и linux-wallpaperengine (portable-сборка) из релизов GitHub с проверкой SHA-256.
- Установка и включение расширения GNOME Shell из комплекта движка.
- Поиск Steam (обычный, snap, flatpak) и папки Мастерской Wallpaper Engine, в том числе в других библиотеках Steam.
- Исправление для snap-Steam: ссылка `~/.steam`, чтобы работала вкладка «Мастерская».
- Служба `we-fix-presets`: пресеты с файлами пользователя больше не показывают пустой экран.
- Автозапуск WE Manager свёрнутым в трей, ярлык в меню приложений.
- Отключение конфликтующего расширения Hanabi (по согласию).
- Повторный запуск обновляет только то, что вышло новее; `uninstall.sh` убирает всё установленное.
