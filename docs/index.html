Как сделать, чтобы Wallpaper Engine работал на Linux Ubuntu

Живые и интерактивные обои из Мастерской Wallpaper Engine прямо на рабочем столе Ubuntu: сцены реагируют на курсор, видео проигрывается, обои выбираются в удобном менеджере. Без Windows, Wine и Proton.

Коротко: установка одной командой

Откройте терминал (Ctrl+Alt+T) и выполните:

curl -fsSL https://raw.githubusercontent.com/makarr2024/we-gnome-installer/main/get.sh | bash

Потом выйдите из сеанса и войдите снова, откройте приложение WE Manager и выберите обои. Нужен Wallpaper Engine, купленный в Steam. Подробности — ниже.

Работает ли Wallpaper Engine на Linux

Официальной версии Wallpaper Engine для Linux нет, а запуск Windows-версии через Proton не кладёт обои на рабочий стол Ubuntu. Но сами обои из Мастерской на Linux показывать можно — для этого есть открытые проекты:

  • linux-wallpaperengine — нативный движок, который рисует сцены, веб-обои и видео из Мастерской;
  • WE Manager — менеджер в стиле Wallpaper Engine: библиотека, Мастерская Steam, плейлисты, настройки;
  • расширение GNOME Shell из комплекта движка — без него на GNOME Wayland обои не попадают под рабочий стол.

Установщик ставит всё это одной командой и исправляет ошибки, на которые обычно натыкаются на Ubuntu: Steam из snap, белый экран у пресетов, конфликт с Hanabi.

Что нужно

СистемаUbuntu 22.04, 24.04 или новее (или другой Linux с glibc 2.35+), процессор x86_64
Рабочий столGNOME — стандартный в Ubuntu. Wayland и X11 подходят
Steamлюбой: из apt, snap («Центр приложений») или flatpak
Wallpaper Engineкупленный и установленный в Steam. Запускать его не нужно
Видеокартас поддержкой OpenGL 3.3 — подходит почти любая встроенная Intel/AMD и NVIDIA
Место на дискеоколо 1,5 ГБ плюс сами обои

Проверено на Ubuntu 24.04 (GNOME 46) и Ubuntu 26.04 (GNOME 50), Wayland, Steam из snap.

Пошаговая установка

Шаг 1. Установите Steam и Wallpaper Engine

Если Steam ещё нет — поставьте его из «Центра приложений Ubuntu» или командой:

sudo apt install steam

Войдите в аккаунт, найдите Wallpaper Engine в библиотеке и нажмите «Установить». Steam может предложить Proton — соглашайтесь, это нужно только для загрузки файлов.

Шаг 2. Запустите установщик

Если нет curl: sudo apt install curl. Затем:

curl -fsSL https://raw.githubusercontent.com/makarr2024/we-gnome-installer/main/get.sh | bash

Установщик:

  • находит Steam и папку Мастерской Wallpaper Engine;
  • скачивает WE Manager и движок linux-wallpaperengine с GitHub и сверяет контрольные суммы SHA-256;
  • ставит и включает расширение GNOME Shell;
  • для Steam из snap создаёт ссылку ~/.steam, иначе Мастерская пишет «Steam not running»;
  • ставит службу we-fix-presets, которая чинит белый экран у пресетов;
  • добавляет WE Manager в меню приложений и в автозапуск;
  • предлагает отключить Hanabi, если он стоит (две программы обоев мешают друг другу).

Всё ставится в домашнюю папку, пароль sudo не спрашивается. Длится несколько минут — скачивается около 400 МБ.

Шаг 3. Перезайдите в систему

Нажмите на меню в правом верхнем углу → «Выключение / Завершение сеанса» → «Завершить сеанс» и войдите снова. GNOME загружает новые расширения только при входе. Без этого обои не появятся.

Как выбрать и поставить обои

  1. Запустите Steam и откройте WE Manager из меню приложений.
  2. Вкладка «Мастерская» — поиск по Мастерской Steam. Фильтр «Тип»: Scene и Web реагируют на курсор, Video просто проигрывается.
  3. Нажмите «Подписаться» один раз. Повторное нажатие — это отписка: Steam удалит файлы.
  4. Дождитесь окончания загрузки («Загрузка… N%»).
  5. Вкладка «Библиотека» → нажмите на обои → «Воспроизвести обои».

Уже скачанные в Steam обои появятся в «Библиотеке» сами (если нет — кнопка сканирования библиотеки).

Чтобы обои оставались после перезагрузки

WE Manager запускается вместе с системой, но после перезагрузки сам включает только плейлист, а не отдельные обои. Поэтому:

  1. «Плейлисты» → создайте плейлист и добавьте в него нужные обои (можно одни).
  2. «Настройки» → автозапуск → выберите этот плейлист.

Установка вручную, без скрипта

Для тех, кто хочет понимать каждый шаг. Это ровно то, что делает установщик.

Показать ручную установку

1. Движок

Скачайте linux-wallpaperengine-generic-portable-x86_64.tar.gz из релизов движка и распакуйте:

mkdir -p ~/.local/share/linux-wallpaperengine-kde
tar -xzf linux-wallpaperengine-generic-portable-x86_64.tar.gz -C ~/.local/share/linux-wallpaperengine-kde --strip-components=1

2. Расширение GNOME

cp -r ~/.local/share/linux-wallpaperengine-kde/gnome-shell-extension/linux-wallpaperengine@wallpaperenginelover.github.io ~/.local/share/gnome-shell/extensions/
gnome-extensions enable linux-wallpaperengine@wallpaperenginelover.github.io

На Wayland команда enable сработает только после перезахода — тогда включите расширение ещё раз или в приложении «Расширения».

3. WE Manager

Скачайте WE-Manager-*.AppImage из релизов WE Manager. Чтобы не ставить libfuse2, распакуйте его:

chmod +x WE-Manager-*.AppImage
./WE-Manager-*.AppImage --appimage-extract
mkdir -p ~/.local/share/we-manager-app && mv squashfs-root ~/.local/share/we-manager-app/
~/.local/share/we-manager-app/squashfs-root/AppRun

4. Steam из snap

[ -e ~/.steam ] || ln -s ~/snap/steam/common/.steam ~/.steam

5. Папка Мастерской

В настройках WE Manager укажите папку …/Steam/steamapps/workshop/content/431960. Для snap-Steam это ~/snap/steam/common/.local/share/Steam/steamapps/workshop/content/431960.

Проблемы и решения

Обои не появились на рабочем столе

Вы не перезашли в систему после установки. Проверьте, что расширение работает:

gnome-extensions info linux-wallpaperengine@wallpaperenginelover.github.io

Должно быть State: ACTIVE (Состояние: ACTIVE). Если INACTIVE — включите его в приложении «Расширения».

«Не удалось загрузить Мастерскую: Steam not running»

  • Запустите Steam и войдите в аккаунт.
  • Окно WE Manager должно быть открыто: свёрнутый в трей, он к Steam не подключается.
  • Steam из snap: должна быть ссылка ~/.steam (её создаёт установщик). Проверка: ls ~/.steam/sdk64/steamclient.so.
  • Закройте Windows-версию Wallpaper Engine, если запускали её через Proton.

Белый или пустой экран вместо обоев

  • Обои удалены — например, после отписки в Мастерской. Подпишитесь заново и дождитесь загрузки.
  • Это пресет (обои на основе других, например к «ASCII Digital Image» со своей картинкой). Движок ищет картинку не там, где она лежит. Служба установщика это чинит; запустить вручную: 
    python3 ~/.local/share/we-gnome-installer/we-fix-presets -v
  • Убедитесь, что скачаны и базовые обои, на которых построен пресет.

Обои не реагируют на звук и музыку

  • Обои слушают звук компьютера — то, что играет в динамиках или наушниках (музыка, YouTube, игры), — а не микрофон. Включите музыку на самом ПК.
  • Реагируют только обои с поддержкой звука (в Мастерской — «Audio responsive»). Обычное видео на звук не реагирует.
  • Проверьте, что движок слушает звук: pactl list source-outputs | grep wallpaperengine — должна быть строка wallpaperengine-audioprocessing.

Значки на рабочем столе моргают при клике

Ошибка расширения GNOME в связке со значками рабочего стола (DING) на GNOME 47 и новее: при клике значки на один кадр оказываются под обоями. Установщик накладывает исправление; оно начинает работать после повторного входа в систему. Если вы ставили раньше — просто запустите команду установки ещё раз и перезайдите.

В списке приложений обои сплющены

Исправляется тем же патчем: в обзоре обои обрезаются по краям, как обычный фон GNOME, а не растягиваются.

После входа в систему обои не включились

WE Manager успел запуститься раньше, чем GNOME загрузил расширение. Установщик запускает его с задержкой 10 секунд; если ставили раньше — запустите команду установки ещё раз.

Поверх обоев видно старое видео / обои мерцают

Работает другая программа обоев — чаще всего расширение Hanabi. Отключите его:

gnome-extensions disable hanabi-extension@jeffshee.github.io

Сцена выглядит не так, как на Windows

Движок поддерживает не все эффекты Wallpaper Engine. Это ограничение linux-wallpaperengine; сообщить о проблеме можно в его трекере.

Ноутбук быстро разряжается

В настройках WE Manager снизьте FPS (например, до 30) и включите паузу на батарее. Обои сами ставятся на паузу, когда окно развёрнуто на весь экран.

Частые вопросы

Нужен ли Windows, Wine или Proton?

Нет. Обои рисует нативный Linux-движок. Из Steam берутся только файлы обоев и ассеты Wallpaper Engine.

Обои реагируют на мышь, как в Windows?

Да — обои типа Scene и Web получают курсор и клики. Видео-обои просто проигрываются.

Обои реагируют на микрофон?

Нет. Как и в Windows, обои реагируют на звук, который играет на компьютере, а не на микрофон.

Работает ли на Wayland?

Да, на GNOME Wayland — через расширение GNOME Shell, которое ставит установщик. X11 тоже поддерживается.

Можно ли без покупки Wallpaper Engine?

Нет. Мастерская и ассеты движка доступны только владельцам Wallpaper Engine в Steam.

Подойдёт для Linux Mint, Kubuntu, Fedora?

Установщик рассчитан на GNOME и проверен на Ubuntu 24.04. На Fedora с GNOME должен работать. На KDE (Kubuntu), Cinnamon (Linux Mint) и других окружениях сам движок работает, но расширение GNOME к ним не относится — WE Manager подскажет, что нужно для вашего рабочего стола.

Это безопасно?

Установщик ставит всё в домашнюю папку без sudo, скачивает программы только из их официальных релизов на GitHub и проверяет контрольные суммы SHA-256. Код установщика открыт для чтения: github.com/makarr2024/we-gnome-installer.

Как обновить?

Запустите команду установки ещё раз — скачается только то, что вышло новее.

Удаление

~/.local/share/we-gnome-installer/uninstall.sh

С параметром --purge удалятся и настройки WE Manager. Обои из Мастерской и Steam не затрагиваются.
